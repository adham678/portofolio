# Adham Youness — Portfolio

A GitHub Pages-ready personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/profile.jpg`

## Deploy on GitHub Pages
1. Create or open a GitHub repository.
2. Upload all files/folders while preserving the structure above.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the branch containing `index.html` and the `/ (root)` folder.
6. Save and wait for GitHub Pages to publish.

## Important
The profile image path is:
`assets/profile.jpg`

Keep the lowercase `assets` folder and `profile.jpg` filename exactly as shown because GitHub Pages paths are case-sensitive.

## Before publishing
Replace:
`YOUR_EMAIL@example.com`
in `index.html` with the email address you want visitors to use.
